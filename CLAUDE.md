# Spectrogram

Browser spectrogram tool for a speech and hearing science course. Spec: `docs/SPEC.md`.

## Agent skills

### Issue tracker

Issues live in GitHub Issues on Allerseelen/Spectrogram, managed with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default five-role vocabulary: needs-triage, needs-info, ready-for-agent, ready-for-human, wontfix. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
